# Student Information Portal

A React application for DCIT26 Laboratory Exercise 2: React Routing and Reusable JSX.

## Requirements
- Node.js (LTS recommended)
- npm

## Run the project
1. Extract this folder.
2. Open the folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Included features
- Reusable Navbar, StudentCard, and CourseCard components
- Home, Students, Courses, and About pages
- React Router routes: `/`, `/students`, `/courses`, and `/about`
- Responsive CSS styling

## Customize
Edit the sample student and course arrays in `src/pages/Students.jsx` and `src/pages/Courses.jsx`.
The sample names and records are demonstration data; replace them with your actual class information if required.
